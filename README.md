## The entry

> A micro-startup that turns your lazy AI agent's raw API bills into itemized expense reports for 2 cents a receipt, so it never lifts a finger.

## How it works

`main.py` (pure Python 3.13 standard library, no dependencies) writes the pitch above — exactly 142 characters, no trailing newline — to `$MAKEFUN_OUTPUT_DIR/entry.txt`, creating the output directory if needed. Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/absurd-out python3 main.py
```

The buyer is the agent's operator, who needs clean books; the revenue is 2 cents a receipt; and the agent itself never lifts a finger.
